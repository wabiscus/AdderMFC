# AdderMFC

Exercice technique réalisé en C++ avec MFC.

## Fonctionnalités

- Addition de deux nombres
- Validation des entrées
- Affichage du résultat
- Journalisation de l'opération
- Menu contextuel accessible au clic droit

## Compilation

Projet Visual Studio / MFC.

Ouvrir `AdderMFC.sln` avec Visual Studio et compiler en configuration Debug ou Release.

## Génération des logs

Les logs sont générés automatiquement lors de l'utilisation de l'application.

Le fichier de log est créé dans le répertoire d'exécution de l'application.
